# NXN1X 2.0 — emulator source

This folder is the emulator part of NXN1X 2.0: the Eden-based core (loaders, HLE services, NCE, shader recompiler, Vulkan renderer, Qt frontend).

See the repository's [README](../README.md) for what NXN1X 2.0 is (SnapRYU 2.0 skeleton, NVIDIA N1X target), how to build it, and the [technical document](../docs/NXN1X_2.0_TECHNICAL.md) ([English](../docs/NXN1X_2.0_TECHNICAL_EN.md)).

이 폴더는 NXN1X 2.0의 에뮬레이터 부분(Eden 기반 코어: 로더, HLE 서비스, NCE, 셰이더 변환기, Vulkan 렌더러, Qt 프론트엔드)입니다. 개요와 빌드는 저장소의 [README](../README.md), 자세한 내용은 [기술 문서](../docs/NXN1X_2.0_TECHNICAL.md)를 보세요.
